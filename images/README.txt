PUT YOUR PHOTOS IN THIS FOLDER
==============================

1) Saree -> Gown slider (shown in the "Saree to Gown" section)
   - images/saree-before.jpg   (photo of the saree)
   - images/gown-after.jpg     (photo of the gown stitched from it)
   Use exactly these two file names. Until you add them, a placeholder is shown.

2) Collection photos (dresses, gowns, dress materials, tops)
   - Copy the photo here, e.g.  images/dress3.jpg
   - Open script.js, find the GALLERY list at the top and add one line:
       { src: "images/dress3.jpg", title: "Diwali Special Dress", cat: "dresses" },
   - cat can be: dresses, gowns, materials, tops

3) Tip: keep each photo under 500 KB so the website opens fast on mobile.
   (Use any free online "compress image" tool.)

4) Also keep your logo file  logo2.png  next to index.html (NOT inside this folder).
